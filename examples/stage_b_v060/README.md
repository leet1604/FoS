# Stage B v0.6 fixture examples

These files are deterministic fixture demonstrations, not live efficacy claims.

- `conservative_needs_validation.fixture.json`: low-support MMP candidate is retained in the validation queue rather than reported as optimized.
- `recovery_dynamic_discovery.fixture.json`: MMP acceptance, evidence expansion, backtracking, and measured-analog retrieval are all visible in one trajectory.
- `*_summary.json` / `*_summary.csv`: proposal-ready metrics generated by `scripts/summarize_stage_b_run.py`.
